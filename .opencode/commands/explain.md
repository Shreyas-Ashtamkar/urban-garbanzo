Explain how the code in $ARGUMENTS works, including:

1. **Overview**: What is this module/function's purpose?
2. **Key components**: What are the important parts?
3. **Data flow**: How does data move through this code?
4. **Dependencies**: What does it depend on?
5. **Edge cases**: What special scenarios does it handle?
6. **Why**: Why was it designed this way?

Make it clear enough for a new team member to understand.
